# Le Grand Malaba

Social media boosting dashboard for Le Grand Malaba — automated engagement services, payment integration, and customer management. Built with PHP and MySQL.

## Features
- Social media service ordering
- Automated order processing
- Customer dashboard
- Payment integration
- Admin panel
- Child panel/reseller system

## Tech Stack
PHP, MySQL, Apache, HTML/CSS/JS

## Requirements
PHP 7.4+, MySQL 5.7+

## Installation
```bash
git clone https://github.com/xdigitexai/legrandmalaba.git
mysql -u user -p db < database/schema.sql
# Configure config/database.php
```
